# 投稿パック

`/app/packs` は、1つの Seed を「完成文 + 素材 + 投稿先 + 進捗」として扱う実運用向けの投稿ワークスペースです。

## 目的

公開予定（Queue）はジョブ単位の詳細管理に向いています。一方、普段の投稿作業では「この発信を X / Instagram / YouTube / TikTok / note に順番に出し切る」という Seed 単位の視点のほうが自然です。

投稿パックは既存データから自動的に組み立てるため、新しいDBテーブルや移行は不要です。

- Seed = 投稿パック本体
- `targetChannels` = 投稿先
- Draft Revision = 承認済みの完成文
- Asset = 画像 / 動画 / 音声 / 資料
- Publish Job = 各媒体の投稿進捗

## 1媒体ごとの状態

- **下書き未承認**: 対象媒体だが承認済みRevisionがまだない
- **承認済み**: 完成文はあるが公開予定へ未追加
- **投稿待ち**: 公開予定へ追加済みで、SNSへ渡せる
- **要確認**: Publish Job が失敗状態
- **キャンセル済み**: Publish Job をキャンセル済み
- **投稿済み**: My-SNS上でも投稿完了として記録済み

## 投稿作業

1. 投稿パックを開く。
2. 「次に投稿」の媒体を確認する。
3. 必要ならタイトル / 本文 / キャプションを個別コピーする。
4. 同じカード内のSeed素材を開く、または保存する。
5. 「○○へ投稿」で媒体自身の投稿画面を開く。
6. 最終プレビューを確認して媒体側の公開ボタンを押す。
7. My-SNSへ戻り「投稿済みにする」。
8. 次の媒体へ進む。

全対象媒体が `投稿済み` になると投稿パックは100%・完了扱いになります。

## 媒体別コピー

YouTube と note は、貼り付け先が分かれているためタイトルと本文系を別ボタンでコピーできます。

- YouTube: `タイトル` / `説明文`
- note: `タイトル` / `本文`
- Instagram / TikTok: `キャプション`
- X / Threads / Facebook / LINE: `投稿文`

## 無料投稿モード

デフォルトの zero-cost モードでは、投稿パックから有料SNS投稿APIを呼びません。既存のハンドオフ方式を利用し、承認済み文章をコピーして媒体自身の投稿画面を開きます。

`/app/queue` は引き続き、失敗・キャンセル・API-firstモードなどを含むジョブ単位の詳細確認画面として残します。
