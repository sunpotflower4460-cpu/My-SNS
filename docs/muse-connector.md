# スマホの Muse から My-SNS を使う

Meta の「Muse from Meta」で、My-SNS の要対応を確認したり、チャットでまとめた文章やリンクを発信素材として保存したりできます。Meta の公開ディレクトリへの登録は不要です。[Muse のカスタムコネクターの案内](https://www.meta.com/help/superintelligence/1687253048996149/)に従って、利用者自身の Muse に設定します。

## 初回だけ

1. スマホの Muse のチャットに、下の依頼文を貼り付けます。独自ドメインの場合はホスト名を置き換えてください。
2. Muse が表示したリンクを開きます。必要に応じて My-SNS にログインし、ワークスペースのオーナーまたは管理者として **承認して Muse に戻る** を押します。素材保存のチェックを外すと、状況確認だけを許可できます。
3. Muse に「My-SNS の要対応を確認して」と依頼します。確認待ちの下書き、期限を迎えた投稿、投稿エラー、受信箱の要対応の件数と、My-SNS を開くリンクが返ります。

> My-SNS をカスタムコネクターとして追加して。MCP サーバーは https://my-sns-yoshirouself.vercel.app/api/muse/mcp です。OAuth のクライアント ID は my-sns-muse で、クライアントシークレットは不要です。状況の確認と発信素材の保存を使いたいので、承認リンクを表示してください。承認後は要対応件数を確認してください。

「このメモを My-SNS に発信素材として保存して。開くリンクを返して」と頼むと、取り込み済みの発信素材（Seed）が1件できます。Muse のリンクをスマホで開けば、必要に応じてログインし、該当するワークスペースと素材へ進めます。写真や動画は素材の画面で追加してください。コネクターを設定できない場合も、Muse で文章をコピーして **Muse 連携 → 文章を貼り付けて発信を作る** から続けられます。

素材を保存するワークスペースでは、My-SNS で **発信スタイル** を設定してください。

接続はワークスペースごとに1つで、有効期間は90日です。期限切れ時は Muse から再接続できます。My-SNS の **ホーム → Muse 連携** で接続を解除できます。Muse から API キーを求められた場合は、同じ画面の **接続キーを手動で発行** を使い、Muse の認証情報の入力欄に登録してください。

## 管理者向け

My-SNS のデプロイに `20261115000000_muse_connector.sql` と `20261115000100_muse_oauth.sql` を順番に適用してください。Muse からアクセスするには、MCP と OAuth のメタデータを取得できる公開 HTTPS URL が必要です。

OAuth クライアント ID は `my-sns-muse` です。S256 PKCE を使い、リダイレクト先は `https://muse.ai/api/hatch/oauth/callback` と `https://agent.meta.ai/api/hatch/oauth/callback` に限定しています。`muse:read` は要対応件数の確認、`muse:capture` は発信素材の保存を許可します。

| エンドポイント | 動作 |
| --- | --- |
| `POST /api/muse/mcp` | Muse のカスタムコネクターが使う MCP サーバー |
| `GET /api/muse/v1/openapi` | 認証不要。コネクターの入出力とエラーの仕様 |
| `GET /api/muse/v1/status` | 読み取り。要対応の件数とアプリのリンクのみ |
| `POST /api/muse/v1/seeds` | 書き込み。許可されたキーで、文章・リンクを1件の発信素材として保存 |

認証は `Authorization: Bearer <接続キー>` です。書き込みは1ワークスペースにつき1時間に30件まで。応答が確認できないときは同じ `requestId` と内容で再試行します。リンクの自動取得、既存の素材の編集、投稿の予約・承認・公開、受信箱の本文取得・返信は API の対象外です。
